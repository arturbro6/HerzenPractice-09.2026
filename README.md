# Учебная практика 2026

Электронное портфолио Борисова Артура Александровича по учебной технологической практике, проходившей с 1 по 28 сентября 2026 года в НО «Ассоциация любителей гребного спорта».

Основой практической части является завершённое консольное TODO-приложение на Go. Проект моделирует учёт организационных задач: добавление, просмотр, изменение, удаление и отметку выполнения. Материалы по дальнейшему развитию отражают анализ возможных решений и не означают, что перечисленные функции уже реализованы.
