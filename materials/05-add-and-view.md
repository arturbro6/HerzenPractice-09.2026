# Добавление и просмотр задач

## Добавление

Функция добавления получает средство чтения ввода, текущую map задач и адрес следующего идентификатора. Введённая строка очищается от переноса строки и пробелов по краям, затем создаётся новая структура `Task`.

Новая задача сохраняется в map по текущему идентификатору, после чего значение следующего ID увеличивается. Начальное состояние новой задачи — `Done = false`.

## Просмотр

При пустой map приложение сообщает, что список пуст. В остальных случаях выполняется перебор записей и выводятся идентификатор, название и обозначение состояния.

## Связь с требованиями практики

Эти операции образуют минимальный рабочий цикл учёта поручений: создать запись и увидеть её в общем списке.

Реализация находится в функциях `addTask` и `showTasks` файла [first.go](../source/first.go).
