# Обзор программных средств

## Go

Go используется как основной язык проекта. Стандартные инструменты позволяют создать модуль, отформатировать исходный код, собрать и запустить программу, а также выполнить тесты без подключения отдельной тестовой библиотеки.

Основные команды:

```text
go mod init <имя-модуля>
go fmt ./...
go run .
go test ./...
```

## Visual Studio Code

Visual Studio Code используется для редактирования файлов Go, навигации по коду и работы со встроенным терминалом. Расширение Go помогает с подсветкой синтаксиса, форматированием и диагностикой.

## Git

Git фиксирует последовательные этапы разработки. Он позволяет увидеть изменённые файлы, сравнить версии и сохранить логически завершённый шаг отдельным коммитом.

## Командная строка

Командная строка связывает инструменты разработки: через неё запускаются команды Go и Git, проверяется структура проекта и выполняется приложение.

## Требования

- установленный Go;
- редактор Visual Studio Code с расширением Go;
- Git;
- терминал операционной системы;
- GitHub-репозиторий для электронного портфолио.
