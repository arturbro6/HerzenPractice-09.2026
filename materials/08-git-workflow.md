# Порядок работы с Git

## Цель

Git используется для сохранения последовательных этапов проекта и публикации электронного портфолио.

## Рабочий цикл

1. Просмотреть состояние файлов.
2. Проверить различия перед сохранением.
3. Добавить относящиеся к одному этапу файлы.
4. Создать содержательный коммит.
5. Отправить изменения в удалённый репозиторий.

Пример команд:

```text
git status
git diff
git add <файлы>
git commit -m "Описание завершённого этапа"
git push
```

## Структура портфолио

- `source` — исходный код и тесты;
- `materials` — отдельный результат по каждому заданию;
- `documents` — задание, отчёт и характеристика;
- `README.md` — содержание с прямыми ссылками.
