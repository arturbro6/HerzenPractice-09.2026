# Руководство пользователя

## Назначение

Консольное TODO-приложение позволяет вести простой список задач: добавлять, просматривать, удалять, переименовывать и отмечать их выполненными.

## Требования

- установленный Go;
- терминал;
- файлы `first.go` и `go.mod` в каталоге проекта.

## Запуск

Из каталога с исходным кодом выполнить:

```text
go run first.go
```

## Команды меню

1. Добавить задачу.
2. Показать задачи.
3. Удалить задачу.
4. Заменить название задачи.
5. Отметить задачу выполненной.
6. Завершить работу.

## Порядок работы

После запуска выбрать номер действия и следовать подсказкам программы. Для операций изменения, удаления и завершения используется ID задачи. При просмотре рядом с каждой записью отображается её состояние.

## Тесты

Файл [first_test.go](../source/first_test.go) содержит автоматические проверки основной логики. Команда стандартного запуска тестов Go:

```text
go test -v
```
