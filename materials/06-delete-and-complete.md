# Удаление и завершение задач

## Удаление

Операция удаления сначала проверяет наличие ключа в map. Если задача найдена, встроенная функция `delete` удаляет запись. При отсутствии ключа коллекция остаётся без изменений.

Функция `deleteTaskByID` отделяет основную логику от пользовательского ввода и поэтому может вызываться из теста с заранее заданным ID.

## Завершение

Функция `completeTaskByID` получает копию структуры из map и признак наличия ключа. Для существующей задачи вызывается метод `Complete`, после чего изменённая копия записывается обратно в map.

При отсутствующем ID функция возвращает исходную коллекцию без изменения других задач.

## Дополнительная операция

Переименование работает по тому же принципу: найденная копия структуры изменяется методом `Rename` и сохраняется обратно по исходному ключу.

Реализация: [first.go](../source/first.go).
