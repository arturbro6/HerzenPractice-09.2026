# Модульное тестирование

## Назначение

Автоматические тесты проверяют основную логику без ручного выбора команд меню. Каждый тест содержит исходные данные, вызов функции, ожидаемый результат, фактический результат и сравнение.

## Подготовленные проверки

- изменение состояния структуры методом `Complete`;
- завершение задачи по существующему ID;
- безопасная обработка отсутствующего ID;
- переименование задачи;
- несколько сценариев переименования;
- удаление существующего и отсутствующего ключа;
- обработка ошибки чтения при добавлении;
- добавление задачи и увеличение следующего ID;
- поиск ID в срезе;
- поиск максимального числа.

## Интерпретация результата

`PASS` означает, что фактическое поведение совпало с заданным ожиданием. `FAIL` сопровождается сообщением о конкретном расхождении и используется для поиска причины ошибки.
