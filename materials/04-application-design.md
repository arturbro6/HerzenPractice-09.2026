# Проектирование приложения

## Основная сущность

Задача представлена структурой `Task` с полями:

- `ID` — числовой идентификатор;
- `Title` — название задачи;
- `Done` — признак выполнения.

## Хранение данных

Задачи хранятся в `map[int]Task`. Ключом является идентификатор, значением — структура задачи. Такой вариант позволяет обращаться к записи по известному ID.

При получении структуры из map создаётся копия значения. Поэтому для изменения состояния выполняются три действия: получить задачу, изменить копию и записать её обратно по тому же ключу.

## Команды приложения

Пользовательское меню поддерживает добавление, просмотр, удаление, переименование, завершение задачи и выход.

## Разделение логики

Для операций, которые удобно проверять автоматически, выделены функции, принимающие данные и идентификатор без чтения из терминала. Пользовательские функции получают ввод и передают выбранные значения основной логике.
