# Настройка среды разработки

## Состав рабочего места

Рабочее место включает Go, Visual Studio Code, Git и командную строку. Проект организован как отдельный Go-модуль.

## Последовательность подготовки

1. Проверить доступность Go командой `go version`.
2. Открыть каталог проекта в Visual Studio Code.
3. Создать или проверить файл `go.mod`.
4. Разместить приложение и тесты в одном пакете `main`.
5. Использовать форматирование Go перед фиксацией изменений.
6. Сохранять этапы разработки в Git.

## Структура завершённого проекта

```text
source/
├── first.go
├── first_test.go
└── go.mod
```

Исходные файлы проекта опубликованы в каталоге [source](../source/). Повторный запуск и изменение завершённого TODO v1.0 при подготовке портфолио не выполнялись.
